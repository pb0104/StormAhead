What the system does today

The server engine is rule-based on real data. The ops console is the only UI surface: it pulls scene, assessment, atmosphere, buildings and evaluation from the API, merges BIPAD / Google / OpenCelliD / night-lights / Reddit layers on the client, and still replays a hand-picked closure snapshot when you hit Run. Live API, snapshot Run

The console loads scene, assessment, atmosphere, buildings, scorecard and verification from the server. The Run button still replays 12 closures and 6 cut-off pockets picked once from the engine.

Real so far

OSM roads and 7,115 buildings; UNOSAT flood; BIPAD facilities, gauges, alerts and 18 landslides; Google Places care homes, fire/police and 59 food shops; Open-Meteo rain and atmosphere; 328 cell sites; 9 night-light outages; IODA; 183 Reddit posts; Maxar before/after mosaics. Radio, helipads and depot stock stay simulated.

No LLM in the loop

Every agent is a deterministic rule or a small model. Social translations were done offline into the feed file. The engine labels events rule-based and never presents them as AI reasoning.

Nothing is saved

Assigning a team or issuing an alert changes the screen only. No action is stored, so the system cannot learn from what the analyst did.
